# eventflow-media
Central media library for EventFlow: design references, reusable assets, static visuals, animations, and template resources for all products


## How AI assistants must use this repository

This is the central visual reference and reusable-media library for EventFlow. It is separate from application code and project specifications.

At the start of any design, animation, template, or visual-implementation task, assistants must:

1. Inspect this repository's current `main` tree; do not rely on old chat summaries or ask the owner to re-send material already stored here.
2. Read `ASSET_INDEX.md` and the README/scenario brief in the relevant product/style folder.
3. Locate reference files by their stable Asset IDs and index paths. Review the actual files when the available tools support visual inspection; do not infer visual details from filenames alone.
4. Respect version and status fields. Only `approved` versions are production-ready; `draft` references inform exploration but are not approved assets.
5. Keep reference material (`references/`) distinct from EventFlow-owned/reusable implementation assets (`assets/`). A reference is inspiration/evidence, not automatically an asset licensed for production.
6. When a material is added, update `ASSET_INDEX.md` with its permanent ID, metadata, rights/usage, version, status, variants, and exact paths.
7. Never ask the owner to upload a reference again until checking this repository and confirming that the required file is genuinely absent or unreadable through available integrations.
